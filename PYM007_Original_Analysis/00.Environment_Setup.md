# Environment Setup 
*** 

## Requirements 
- [bamtofastq](https://github.com/jts/bam2fastq) program installed and accessible in your environment -> ***Only required if using Step 2***
> **Note:** This program is not installed in the LAVIS Cluster
*** 

## Instructions
> **Note:** Make sure to run all these commands from your project's main directory
### 1. Retrieve Raw Sequencing Files
We first downloaded the raw read files directly from the BYU server, since they were responsible for the sequencing. Make sure to replace the text inside the brackets with your actual username, password, and the full URL path to each file.
> **Note:** This step may vary depending on your data storage location and transfer method. If your files were provided through another method or format, adjust accordingly.
```bash
# 1. Create a directory to store all the raw reads files
mkdir Raw_reads

# 2. Download raw data - Repeat for each sequencing cell file
cd Raw_reads
wget --user [USER] --password [PASSWORD] https://files.rc.byu.edu/[wholepath] 
```
### 2. Preprocessing of unmerged raw reads (Only for unmerged uBAM files from individual sequencing cells)
If the sequencing reads were provided as unaligned BAM (uBAM) files (PacBio’s native format for storing reads), you’ll need to convert and merge them into a single FASTQ file to ensure compatibility with downstream analysis tools. 
```bash
# 1. Create a directory to store all the unmerged reads
mkdir Raw_Reads/Unmerged

# 2. Move all the unmerged reads into the Unmerged directory
mv Raw_Reads/*.bam Raw_Reads/Unmerged

# 3. Convert ubam files to .fastq files
cd Raw_Reads/Unmerged
bam2fastq *.bam

# 4. Merge all fastq files together. Make sure to replace the text inside the brackets with your sample name, and delete the .gz suffix if the fastq files are not compressed
cat *.fastq.gz > [PYM007]_merged_reads.fastq.gz
mv [PYM007]_merged_reads.fastq.gz ..
```
