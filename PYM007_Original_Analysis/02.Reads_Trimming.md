# Cleaning and Trimming of Reads 
*** 

## Requirements 
- [HiFiAdapterFilt](https://github.com/sheinasim-USDA/HiFiAdapterFilt) v.2.0.0 or later installed and accessible in your environment
- [blast+](https://github.com/ncbi/blast_plus_docs) v.2.13.0 or later installed and accessible in your environment
- [bamtools](https://github.com/pezmaster31/bamtools) v.2.5.1 or later installed and accessible in your environment
> If you're using the LAVIS Cluster, load the programs as follows:
  ```bash
module load hifiadapterfilt/2.0.0
module load blast+/2.13.0
module load bamtools/2.5.1
  ```
*** 

## Instructions
> **Note:** Make sure to run all these commands from your project's main directory
### 1. Environment Setup 
Before performing the cleaning of the raw data, create a specific directory for the process:
```bash
mkdir Reads_Trimming
cd Reads_Trimming
```
### 2. HiFiAdapterFilt Analysis 
```bash
pbadapterfilt.sh -p ../Raw_Reads -l 44 -m 97 -t 60 -o Hifiadapterfilt
```
Relevant information regarding the command's arguments:
- `-p` option indicates the file prefix (path), not the file itself. 
- You can modify the minimum length of adapter match to remove (`-l`), the minimum percent match of adapter to remove (`-m`), or the number of threads (`-t`) as needed.
### 3. Quality Control of Trimmed Reads (Optional)
To determine whether there was an improvement in data quality after the trimming process, LongQC and FastQC must be run again using the filtered FASTQ file obtained in step 2 as input. Make sure to edit the text within the brackets as needed (more information in the `1.Reads_Quality_Control.md` file
```bash
# Load QC modules
module load anaconda3/2021.05
module load longqc/1.2.0
module load fastqc/0.11.3

# LongQC analysis
python [/cm/shared/apps/longqc/LongQC-1.2.0/longQC.py] sampleqc -x pb-hifi -s [PYM007] -p 80 -o LongQC ./Hifiadapterfilt/[PYM007_reads.filt.fastq.gz]

# FastQC analysis
mkdir FastQC
cd FastQC
fastqc ../Hifiadapterfilt/[PYM007_reads.filt.fastq.gz]
```
