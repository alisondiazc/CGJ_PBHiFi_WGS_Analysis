#### 1.2. GRCh38 Reference Assembly File 
> **Note:** If you're working on the LAVIS Cluster, these files are already available in the `/mnt/Timina/cgonzaga/resources/GRCh38.14` directory as `Homo_sapiens_GRCh38.p14.noMT.names.fasta` and `Homo_sapiens_GRCh38.p14.noMT.names.fasta.fai`. These files have already been edited to contain only the 24 human chromosomes (1–22, X, and Y), excluding the mitochondrial genome and alternate/patch scaffolds, with each chromosome header renamed as "1", "2", etc.

The GRCh38 Reference Assembly file is obtained directly from the NCBI database using wget:
```bash
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/001/405/GCA_000001405.29_GRCh38.p14/GCA_000001405.29_GRCh38.p14_genomic.fna.gz
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/001/405/GCA_000001405.29_GRCh38.p14/GCA_000001405.29_GRCh38.p14_assembly_report.txt
# It is recommended to also download the README file for future reference:
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/001/405/GCA_000001405.29_GRCh38.p14/README.txt
```
This file is unfiltered, so it needs to be edited to retain only the sequences corresponding to the 24 human chromosomes (1–22, X, and Y), as follows:
```bash
# 1. Unzip the downloaded fna file:
gunzip GCA_000001405.29_GRCh38.p14_genomic.fna.gz
# 2. Generate an index file to use in chromosome extraction and naming:
grep -v "^#" GCA_000001405.29_GRCh38.p14_assembly_report.txt | awk -F'\t' '$2=="assembled-molecule"{print $5"\t"$1}' > index.tsv
# 3. Extract each chromosome and rename the headers as 1,2,..,22, X & Y:
module load seqtk/1.2-r94
for chr in $(seq 1 22) X Y
do
  acc_no=$(awk -v c="${chr}" 'BEGIN{FS="\t"}{if($2==c){print $1}}' index.tsv)
  seqtk subseq GCA_000001405.29_GRCh38.p14_genomic.fna <(echo "${acc_no}") | \
  sed "1s/.*/>${chr}/"
done > Homo_sapiens_GRCh38.p14.noMT.names.fasta
```
Finally, an index file must be created for the cleaned reference file using samtools: 
```bash
module load samtools/1.16.1
samtools faidx Homo_sapiens_GRCh38.p14.noMT.names.fasta
```

### 2. Post-Alignment Quality Control 
#### 2.1 Quality Control Tools
- R v.4.0.2 or later installed and accessible in your environment
- Python v.3.3 or later installed and accessible in your environment
- [mosdepth](https://github.com/brentp/mosdepth) v.0.3.3 or later installed and accessible in your environment
- [samtools](https://github.com/samtools/samtools) v.1.16.1 or later installed and accessible in your environment
- [assembly-stats](https://github.com/sanger-pathogens/assembly-stats) v.1.0.1 or later installed and accessible in your environment
- [minimap2](https://github.com/lh3/minimap2) v.2.24.0 or later installed and accessible in your environment
- [pafr](https://github.com/dwinter/pafr) library installed and accessible in your environment
> If you're using the LAVIS Cluster, load the programs as follows:
  ```bash
module load r/4.0.2
module load python38/3.8.3
module load mosdepth/0.3.3
module load samtools/1.16.1
module load assembly-stats/1.0.1
module load minimap2/2.24
  ```

- [mosdepth](https://github.com/brentp/mosdepth) script `plot-dist.py` accessible in your environment
- [QUAST](https://quast.sourceforge.net/) script `quast.py` accessible in your environment
- [dotPlotly](https://github.com/tpoorten/dotPlotly) script `pafCoordsDotPlotly.R` accessible in your environment
