#### 1.2. CHM13-T2T Reference Assembly File 
> **Note:** If you're working on the LAVIS Cluster, these files are already available in the `/mnt/Timina/cgonzaga/Resources/T2T_2.0` directory as `chm13v2.0.noMT.names.fa` and `chm13v2.0.noMT.names.fa.fai`. These files have already been edited to contain only the 24 human chromosomes (1–22, X, and Y), excluding the mitochondrial genome, with each chromosome header renamed as "1", "2", etc.

The CHM13-T2T Reference Assembly file can be obtained directly from the [T2T consortium GitHub](https://github.com/marbl/CHM13) using wget:
```bash
wget https://s3-us-west-2.amazonaws.com/human-pangenomics/T2T/CHM13/assemblies/analysis_set/chm13v2.0.fa.gz
# It is recommended to also download the README file for future reference:
wget https://s3-us-west-2.amazonaws.com/human-pangenomics/T2T/CHM13/assemblies/analysis_set/README.txt
```

This file is unfiltered, so it needs to be edited to retain and name only the sequences corresponding to the 24 human chromosomes (1–22, X, and Y). For that process, you will need the following tools installed and accessible in your environment:
- [seqtk](https://github.com/lh3/seqtk) v.1.2 or later installed and accessible in your environment
- [samtools](https://github.com/samtools/samtools) v.1.16.1 or later installed and accessible in your environment
> If you're using the LAVIS Cluster, load the program as follows:
  ```bash
module load seqtk/1.2-r94
module load samtools/1.16.1
  ```
The process to edit the downloaded genome reference as a ".fa.gz" file is the following:  
```bash
# 1. Unzip the downloaded fasta file:
gunzip chm13v2.0.fa.gz
# 2. Extract each chromosome and rename the headers as 1,2,..,22, X & Y:
for chr in $(seq 1 22) X Y
do
  seqtk subseq chm13v2.0.fa <(echo "chr${chr}") | \
  sed "1s/.*/>${chr}/"
done > chm13v2.0.noMT.names.fa
```
Finally, an index file must be created for the cleaned reference file using samtools: 
```bash
samtools faidx chm13v2.0.noMT.names.fa
```
> Note: The index file (*.fai) has to be in the same directory as the reference assembly to avoid errors in the alignment process

## Instructions
> **Note:** Make sure to run all these commands from your project's main directory and edit the text within the brackets as needed
### 1. Environment Setup 
Before performing any alignment on the raw data, create a specific directory for this process:
```bash
mkdir [project_main_dir]/CHM13_Alignment
cd [project_main_dir]/CHM13_Alignment
```
### 2. Read Alignment Against GRCh38 Reference Genome using pbmm2
To keep the alignment step separate from the subsequent quality control steps, create a dedicated directory for the pbmm2 output:
```bash
mkdir [project_main_dir]/CHM13_Alignment/pbmm2_alignment
cd [project_main_dir]/CHM13_Alignment/pbmm2_alignment
```
Once inside the newly created directory, run pbmm2 as follows: 
```bash
pbmm2 align --sort -j 20 --preset HIFI --log-level INFO [/mnt/Timina/cgonzaga/Resources/T2T_2.0/chm13v2.0.noMT.names.fa] [project_main_dir]/Reads_Trimming/[PYM007_reads.filt.fastq.gz] [PYM007].CHM13.pbmm2.bam
```
Relevant information regarding the command's arguments:
- You can modify the number of threads (`-j`) as needed

### 3. Alignment Quality Control (QC)
#### 3.1. Alignment Coverage Assessment
First, create a dedicated directory for Mosdepth: 
```bash
mkdir [project_main_dir]/CHM13_Alignment/mosdepth_QC
cd [project_main_dir]/CHM13_Alignment/mosdepth_QC
```
Then, run the program as follows: 
```bash
mosdepth -t 20 -n [PYM007].CHM13 [project_main_dir]/CHM13_Alignment/pbmm2_alignment/[PYM007].CHM13.pbmm2.bam
```
Relevant information regarding the command's arguments:
- You can modify the number of threads (`-t`) or the results name (`-n`) as needed
Finally, plot mosdepth results using the plot-dist.py script:
> **Note:** You can find the plot-dist.py file in the *Scripts* folder within this repo, or you can download directly from the mosdepth page with "wget https://github.com/brentp/mosdepth/blob/master/scripts/plot-dist.py". Make sure to modify permissions of the script with "chmod 777 plot-dist.py" before running the following command
```bash
python ./plot-dist.py [PYM007].CHM13.pbmm2.mosdepth.global.dist.txt
```
#### 3.2. Consensus sequence generation with Samtools
First, create a dedicated directory for Samtools:
```bash
mkdir [project_main_dir]/CHM13_Alignment/samtools_consensus
cd [project_main_dir]/CHM13_Alignment/samtools_consensus
```
Then, run the program as follows: 
```bash
samtools consensus -f fasta -o [PYM007].CHM13.cons.fa -a [project_main_dir]/CHM13_Alignment/pbmm2_alignment/[PYM007].CHM13.pbmm2.bam
```
